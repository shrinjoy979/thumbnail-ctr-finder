# Thumbnail-CTR-Finder

A simple tool to analyze and compare thumbnail performance using Click-Through Rate (CTR).

This project helps creators and developers evaluate which thumbnails perform better by calculating CTR from impressions and clicks, making it easier to optimize content performance.

---

## Features

- Calculate CTR (Click-Through Rate)
- Compare multiple thumbnails
- Identify best-performing thumbnail
- Simple input: impressions & clicks
- Lightweight and fast
- Clean and easy-to-use logic

---

## Tech Stack

- TypeScript
- Node.js
- Express.js (optional API)
- Basic frontend (optional)

---

## Project Purpose

The goal of this project is to help understand and analyze thumbnail performance using CTR metrics. It is useful for YouTube creators, marketers, and developers experimenting with content optimization.

---
